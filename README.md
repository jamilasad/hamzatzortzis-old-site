# hamzatzortzis.com: archived copy (2017–2026)

A static copy of the final version of [hamzatzortzis.com](https://www.hamzatzortzis.com/), the website of Hamza Andreas Tzortzis. The original went offline in 2026. This copy was rebuilt from Internet Archive (Wayback Machine) captures as reference material for a new website.

- **Not the official site.** Every page carries a notice saying so and is marked `noindex`.
- **Content © Hamza Andreas Tzortzis.** Some pages reflect views the author has since revised or withdrawn.
- **What is here:** 118 pages with the original WordPress theme ("Soledad"), images and links rewritten to work offline and from any sub-path. Tracking scripts are removed and the contact forms are disabled.
- **To view locally,** serve the folder rather than opening the files directly:

  ```bash
  python3 -m http.server 8000
  ```

  Then open http://localhost:8000/.
